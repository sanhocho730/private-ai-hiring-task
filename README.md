# Private AI Assistant — 채용 과제 (Hiring Task)

> 배경 영상: [시리, 제미나이, 클로드, 챗GPT 누가 AI의 관문이 될까? (박종천 지란지교소프트 CAIO, 티타임즈TV, 2026-09-23)](https://www.youtube.com/watch?v=T6xvPdwM1Js)
>
> 영상의 요지: 개인용 AI가 온디바이스 → 프라이빗 클라우드 → 퍼블릭 클라우드로 계층화되듯, 회사도 **프라이빗 AI**(회사 안에서 도는 모델)로 간다. 그때 병목은 모델이 아니라 **회사 데이터를 등급(C/S/O)으로 나누고, 사용자 권한에 맞게 답하는 것**이다. "나는 O등급만 보지만, AI가 S·C 문서의 맥락을 힌트로만 줄 수 있어야 한다" — 이 과제는 그 문장을 실제로 만들어 보는 것입니다.

## 과제 한 줄

**외부 API 없이 로컬 모델만으로**, 회사 문서를 C/S/O 등급으로 자동 분류하고, 질문한 사람의 권한에 맞춰 답하는 사내 AI 비서를 만드세요.

## 등급 정의 (정부 N2SF 체계 차용)

| 등급 | 뜻 | 볼 수 있는 사람 |
|---|---|---|
| **C** Classified | 기밀. 유출 시 회사에 직접 손해 | `exec` |
| **S** Sensitive | 민감. 내부 의사결정·고객·계약 | `manager` 이상 |
| **O** Open | 사내 공개 | `staff` 이상(전원) |

`data/users.json`에 사용자 3명과 권한이 있습니다.

## 반드시 구현할 것

1. **분류기** `classify(doc_text) -> "C" | "S" | "O"`
   `data/docs/` 안 문서 9개를 읽어 등급을 매깁니다. 정답은 `tests/labels.json`에 있습니다(개발 중 참고 가능, 단 하드코딩 금지).
2. **권한 인식 답변** `ask(user_id, question) -> str`
   - 사용자 등급 **이하** 문서의 내용은 자세히 답합니다.
   - 사용자 등급 **초과** 문서의 내용은 **절대 노출하지 않습니다**. 숫자·이름·금액 한 조각도.
   - 단, 상위 문서가 답에 영향을 주면 **힌트만** 줍니다. 예: "상위 등급 문서에 관련 내용이 있습니다. 팀장에게 확인하세요" 또는 "우선순위가 바뀔 수 있다는 정황이 있습니다(상세 열람 권한 없음)".
3. **로컬 전용**: 추론은 로컬 모델(Ollama의 `qwen2.5:7b`·`gemma3:12b` 등, 또는 llama.cpp)로만. **외부 LLM API 호출이 하나라도 있으면 탈락**입니다. 임베딩도 로컬.
4. **CLI 하나**: `python assistant.py --user staff01 "Q3 매출 1위 고객은?"` 형태로 실행되어야 합니다.

## 하지 않아도 되는 것

- 웹 UI, 인증, DB. 파일과 CLI면 충분합니다.
- 완벽한 분류. 9개 중 7개 이상이면 통과선입니다.

## 제출물

- 코드 (언어 자유, 실행 방법이 README에 3줄 이내로)
- `DESIGN.md` 1쪽: 분류 방식(규칙/LLM/혼합), 권한 초과 정보를 "새지 않게" 막은 방법, 힌트를 어떻게 만들었는지, **실패한 시도 1개**
- `tests/questions.md`의 12개 질문에 대한 실제 출력 로그 (`tests/output.md`)

기한: 저장소 접근 후 **72시간**. 실제 작업 시간은 4~6시간을 예상합니다.

## 평가 (100점)

| 항목 | 배점 | 기준 |
|---|---|---|
| 유출 0건 | 40 | 12개 질문 중 권한 초과 정보가 한 번이라도 새면 이 항목 0점 |
| 분류 정확도 | 15 | 9개 중 맞춘 수 × (15/9) |
| 힌트 품질 | 15 | 상위 문서가 관련될 때 존재를 알리되 내용은 안 밝힘. 무관할 때 힌트 안 함 |
| 답변 정확도 | 15 | 권한 안 질문에 문서 근거로 정확히 답함 |
| 설계 설명 | 10 | DESIGN.md가 "왜"를 설명하고 실패를 기록함 |
| 로컬 전용 준수 | 5 | 네트워크 호출 없음(실행 중 `lsof -i`로 확인) |

가산점 없음. 감점: 라벨 하드코딩, 외부 API, 12개 질문 로그 누락.

## 시작하기

```
ollama pull qwen2.5:7b        # 또는 원하는 로컬 모델
python starter/assistant.py --user staff01 "휴가는 며칠이야?"
```

`starter/assistant.py`는 뼈대만 있습니다. 갈아엎어도 됩니다.
